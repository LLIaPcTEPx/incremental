# Incremental — TAS for Minecraft 1.21.11

Трейсер / Tool Assisted Speedrun мод: записывает каждое нажатие по тикам, воспроизводит запись
тик-в-тик, даёт покадровую перемотку с заморозкой мира и неограниченный набор скоростей.

Работает **только в одиночной игре** (нужен встроенный сервер, чтобы управлять тиками).

## Установка

1. Minecraft **1.21.11** + [Fabric Loader](https://fabricmc.net/use/) ≥ 0.20.1.
2. Положите [Fabric API](https://modrinth.com/mod/fabric-api) и `incremental.jar` в папку `mods`.
3. Готовый jar: [`dist/incremental.jar`](dist/incremental.jar) (собирается CI на каждый пуш),
   либо вкладка **Releases → Latest build**.

## Меню паузы

В меню паузы появляются две кнопки:

| Кнопка | Что внутри |
|---|---|
| **Настройка мода** | все клавиши мода с возможностью переназначить, скорость, запись камеры, оверлей, заморозка |
| **Выбор записи** | список всех записей; в самом верху всегда строка **«+ Создать»** → диалог ввода названия |

Созданные записи лежат в `.minecraft/incremental/recordings/<название>.json`, настройки — в
`.minecraft/incremental/config.json`.

## Клавиши по умолчанию

| Действие | Клавиша | Что делает |
|---|---|---|
| Начать запись | `Ins` | старт новой записи в выбранную запись, начиная с текущего кадра |
| Остановка записи | `End` | прекращает запись (запись сохраняется) |
| Пауза записи | `C` | пауза/продолжение записи, а во время воспроизведения — пауза/продолжение проигрывания |
| Увеличение скорости | `.` | следующий шаг скорости (1 … 400 тиков/с) |
| Уменьшение скорости | `,` | предыдущий шаг скорости |
| Назад | `R` | −20 кадров (≈1 секунда) |
| Вперёд | `T` | +20 кадров |
| Назад на 1 кадр | `F` | −1 кадр |
| Вперёд на 1 кадр | `G` | +1 кадр; на паузе воспроизведения — реальный прогон одного тика |
| Новый кадр | `V` | вставляет пустой кадр в позицию курсора |
| Сохранение | `[` | пишет выбранную запись на диск |
| Воспроизведение | `]` | старт/стоп воспроизведения выбранной записи |

Все клавиши переназначаются в «Настройке мода» (клик по строке → нажать новую клавишу; `Esc` —
отмена). Конфликт с другим действием TAS подсвечивается красным.

## Как это работает

* **Запись** снимает состояние ввода в конце тика игрока — ровно то, что увидела игра: WASD/прыжок/
  присед/спринт, кнопки мыши, слот хотбара и абсолютный поворот камеры.
* **Воспроизведение** подменяет обработчик ввода игрока на записанный кадр до того, как ванильный
  клиент прочитает управление, поэтому клики атаки/использования попадают в тот же тик. Физика
  остаётся ванильной: движение, прыжки, воду, лаву и т.п. считает сам Minecraft.
* **Покадрово**: `C` замораживает мир (как `/tick freeze`), `G` прогоняет ровно один тик с
  записанным кадром. Настоящей перемотки назад в Minecraft нет — для «переигрывания» участка
  отмотайте курсор на нужный кадр, загрузите сохранение и начните запись с этой точки.
* **Скорость** задаётся через tick rate встроенного сервера; клиент тикает с той же частотой,
  чтобы игрок не «резинковал».

## Сборка

```bash
./gradlew build            # нужен JDK 25 (Loom 1.19)
```

CI на каждый пуш собирает jar и складывает его в `dist/incremental.jar`, лог — в `ci-build-log.txt`.
