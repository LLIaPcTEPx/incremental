# Incremental — TAS для Minecraft 1.21.11

## Что скачать

**`dist/incremental.jar`** — готовый мод (в этом репозитории, обновляется CI после каждого пуша).
Также доступен во вкладке **Releases → Latest build**.

Нужно: Minecraft **1.21.11**, Fabric Loader ≥ 0.20.1, [Fabric API](https://modrinth.com/mod/fabric-api).
Кинуть `incremental.jar` и Fabric API в `.minecraft/mods`. Работает **только в одиночной игре**.

## Две кнопки в меню паузы (Esc)

```
┌──────────────────────────────────────────┐
│             Настройка мода   Выбор записи │
└──────────────────────────────────────────┘
```

**Настройка мода** — список всех клавиш и параметров:

| Действие | Клавиша по умолчанию |
|---|---|
| Начать запись | `Ins` |
| Остановка записи | `End` |
| Пауза записи | `C` |
| Увеличение скорости записи | `.` |
| Уменьшение скорости записи | `,` |
| Назад | `R` |
| Вперёд | `T` |
| Назад на 1 кадр | `F` |
| Вперёд на 1 кадр | `G` |
| Новый кадр | `V` |
| Сохранение | `[` |
| Воспроизведение выбранной записи | `]` |

Переназначить: клик по строке → нажать новую клавишу (можно мышью). `Esc` — отмена,
кнопка «По умолчанию» возвращает все клавиши из таблицы.

**Выбор записи** — список всех записей. Первая строка всегда **«+ Создать»**, по клику
открывается окно ввода названия. Ниже: Запись / Воспроизвести, Изменить (покадровый просмотр),
Переименовать, Удалить (двойное нажатие = подтверждение), Сохранить.

## Как записать и воспроизвести

1. `Esc` → **Выбор записи** → **+ Создать** → ввести имя → **Создать**.
2. Закрыть меню, встать туда, откуда начинается забег, и нажать `Ins` — пошла запись
   (над хотбаром `● REC`). Мод пишет не только клавиши и камеру, но и координаты игрока в каждом
   тике, поэтому запись «привязана» к месту старта.
3. `End` — запись остановлена и сохранена в `.minecraft/incremental/recordings/<имя>.json`.
4. `]` — воспроизведение выбранной записи: игрок телепортируется в записанные координаты и
   повторяет забег оттуда, где он был записан. `]` ещё раз (или `C`) — пауза/стоп.

При перемотке (`R`/`T`/`F`/`G`) игрок тоже ставится в координаты соответствующего кадра —
видно, где именно проходил забег.

## Перемотка во время записи (как в TAS-редакторах)

* Нажали `R`/`F` во время записи — **запись сама встаёт на паузу**, мир замораживается,
  а строка над хотбаром показывает `❚❚ ЗАПИСЬ ПЕРЕМОТАНА` и `kept N` — сколько кадров осталось
  после курсора.
* Дальше можно ходить по кадрам в любую сторону (`F`/`G`, `R`/`T`) — каждый кадр ставит игрока
  в свои координаты.
* `G`/`T`, дойдя до места, где запись остановилась, **включают запись обратно**. Либо сразу
  нажмите `Ins`/кнопку «Продолжить» — запись продолжится с текущего кадра.
* **Ничего не стирается.** Новые кадры перезаписывают старые начиная с курсора, а остаток
  записи после них сохраняется. Раньше запись с перемотанной точки удаляла весь хвост — это
  исправлено.
* `End` останавливает запись и сохраняет всё, включая сохранённый хвост.

## Семантика клавиш

| Клавиша | Смысл |
|---|---|
| `Ins` | начать новую запись в выбранную запись, **начиная с текущего кадра и текущего места** |
| `End` | прекратить запись (последующие действия не пишутся), запись сохраняется |
| `C` | пауза/продолжение записи; во время воспроизведения — пауза/продолжение проигрывания |
| `.` / `,` | **скорость записи** 1 … 400 тиков/с (20 = обычная); действует и на запись, и на воспроизведение, чтобы не ждать долгий забег |
| `R` / `T` | −20 / +20 кадров |
| `F` / `G` | −1 / +1 кадр; на паузе проигрывания `G` реально прогоняет один тик, а `F` возвращает игрока в координаты предыдущего кадра |
| `V` | вставить пустой кадр в позицию курсора |
| `[` | сохранить выбранную запись на диск |
| `]` | воспроизвести / остановить выбранную запись |

**Покадровая работа.** `C` на паузе замораживает мир (как `/tick freeze`), `F`/`G` двигают
курсор по кадрам, `G` на паузе воспроизведения прогоняет ровно один тик с записанным кадром.
Настоящей перемотки назад в Minecraft нет: чтобы «переиграть» участок — отмотайте курсор на нужный
кадр, загрузите сохранение и нажмите `Ins` (запись начнётся с этого кадра).

**Что пишется в кадре:** WASD, прыжок, присед, спринт, кнопки мыши, слот хотбара и поворот
камеры (абсолютный, поэтому не зависит от чувствительности мыши).

## Файлы

```
.minecraft/incremental/config.json               настройки и клавиши
.minecraft/incremental/recordings/<имя>.json    записи
```

## Если что-то не так

* Мод не грузится — проверьте, что версия Minecraft 1.21.11 и Fabric Loader ≥ 0.20.1.
* Кнопки не появились в паузе — мод работает только в мире (не в главном меню).
* В мультиплеере TAS отключён: заморозка, скорость тиков и телепорт в записанные координаты
  требуют встроенного сервера.
* Координаты пишутся в каждом кадре. Старые записи без координат продолжают работать:
  они повторяют только ввод и камеру.
* «Скорость» в настройках — это скорость записи: на 5x забег записывается в пять раз быстрее
  реального времени (и так же быстро проигрывается).
